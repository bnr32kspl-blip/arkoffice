# 閉域網向け検証チェックリスト

自治体・医療機関などへのパイロット配布前に、本リストで確認してください。

関連仕様: [`local-llm-runtime.md`](local-llm-runtime.md)（ARKOFFICE-SPEC-LLM-001）

## ビルド / ライセンス境界

- [ ] `npm run check:no-ee` が成功する（`ee/` ツリー無し）
- [ ] `npm run check:trademarks` が成功する
- [ ] `npm run check:airgap` が成功する
- [ ] ルートの `LICENSE` が Apache-2.0 であり、`NOTICE` に upstream 帰属が残っている
- [ ] インストーラの製品名・About UI が **ArkOffice** のみを表示する（upstream 製品ブランド無し）

## オフラインインストール

- [ ] 承認済みオフライン媒体でインストーラを移送した（インストール時の CDN 取得無し）
- [ ] ネットワークアダプタ無効、または外向き拒否のファイアウォール下でアプリが起動する
- [ ] Docs / Sheets / Slides / PDF がネットワーク無しでサンプルファイルを開閉・保存できる
- [ ] 同梱フォントがインターネットからフォントを取得せずに表示される

## パッケージ（ローカル LLM ランタイム）

リリース成果物（`apps/shell/release` 等）または展開イメージで:

- [ ] `resources/llm/` に `llama-server-cuda.exe` / `llama-server-vulkan.exe` / `llama-server-cpu.exe` がある（AC-6）
- [ ] インストーラ／展開媒体に **GGUF は含まれない**（別途 `%ProgramData%\ArkOffice\models` へ配置）
- [ ] リリースノートにインストーラサイズ増と「CUDA 版は NVIDIA ドライバ前提」が記載されている
- [ ] ビルド前に `apps/shell/vendor/llm/` へバイナリを配置した（未配置だと `extraResources` に llm が入らない）

## AI（ローカル・同梱ランタイム）

前提: Windows x64、vendor に少なくとも CPU バイナリ、モデルフォルダに GGUF を配置。

- [ ] **AC-1** 単一 GGUF のみでローカルモードの短い AI 編集が成功する
- [ ] **AC-2** 複数 GGUF 時、未選択ならファイル名ソート先頭が選ばれる（設定／ウィザードで確認）
- [ ] **AC-3** リモートモードでは同梱 `llama-server` プロセスが起動しない（タスクマネージャ等）
- [ ] **AC-4** リモート Base URL を自由入力し、推論ホストへ接続できる
- [ ] **AC-5** バックエンドを `auto` / `cuda` / `vulkan` / `cpu` に切り替え、対応環境で起動（非対応は明確なエラー）
- [ ] **AC-7** 2 クライアント同時リクエスト時、後発の AI パネルに「順番待ち」が表示される
- [ ] **AC-8** LAN オプトイン OFF（既定）では他端末から推論ポートに接続できない（`127.0.0.1` のみ）
- [ ] **AC-9** 推論ホストで LAN オプトイン ON のとき、他端末がリモートモードで接続できる（FW は拠点内のみ）
- [ ] **AC-10** タイムアウトは既存値のまま（接続 60s / アイドル 60s / 非ストリーム 180s）
- [ ] **AC-11** 初回ウィザードと「AI 推論の設定」の両方からモード・モデルを変更できる
- [ ] LLM 停止時は明確な接続エラーになり、クラウドへの無言フォールバックが無い
- [ ] インターネット遮断下で Docs の短い AI 編集が成功する
- [ ] `GET http://127.0.0.1:8080/arkoffice/queue` が JSON を返す（ローカルモード稼働時）

手動で外部 `llama-server` のみ使う場合（同梱無し）:

- [ ] AI 設定のプロバイダが **Local (llama.cpp)** で、拠点の base URL になっている
- [ ] 待ち行列 UI はプロキシ非対応ホストでは出ないことがある（仕様どおり）

## 承認なしでは OFF のままにすべき機能

- [ ] 自動更新がどのホストにも接続しない（`ARKOFFICE_AUTO_UPDATE` 未設定 / 設定で無効）
- [ ] `ARKOFFICE_ALLOW_WEB_SEARCH=1` 無しでは Web 検索ツールが無効 / 空を返す
- [ ] AI 利用に第三者 SaaS へのサインインが不要

## セキュリティ / 運用

- [ ] コード署名に展開組織の証明書を使用している（またはリスクを受容している）
- [ ] ネットワーク許可リストを確認した: [`network-allowlist.md`](network-allowlist.md)
- [ ] 展開手順書を確認した: [`air-gapped-deployment.md`](air-gapped-deployment.md)
- [ ] 利用する組織設定サンプル（ある場合）が `docs/examples/` の内容と拠点ポリシーに一致する
